# /mumble-polish

## Shortcuts

Shortcuts needs to be in a better place. If we remove the "Listening Now" square from the homepage — which we're already doing — we might actually have some space to put the global shortcuts in that little area. The idea is: everything in one place, more than just dictation. Move from the first word to finishing your work without breaking your flow. That belongs on the home page.

## Deck (Smaller Devices)

Massive, massive improvements on the Deck. I love what you've done with it. It's just so much better. It looks so much better.

But on smaller devices, the Deck becomes very squished and very big. Find a way on smaller devices for it to kind of — actually, the Deck contents, the filter with transcripts, keyboard prompts, emails, and all — when you actually go on a smaller device and the width shrinks, it opens up a slider, which just looks really bad. Fix the responsive behaviour so it collapses gracefully without that ugly slider.

## Search UI

The UI for search is kind of bad in that it's not really Mumble-like. It's not digital glass, liquid glass, Mumble-type flashy gold and black design. It looks a little bit different — like it belongs to a different app. Study the UX and UI for Mumble and replicate that properly.

But not only that — the icons for the applications are kind of messed up. You should have the exact icons for each of these applications. For example, the Brave icon is flipped 180 degrees. It just doesn't make any sense. Settings doesn't have an icon. There are so many applications without icons. You need to find a way to consistently pull the correct icons for every application. No placeholders, no flipped ones, no missing ones.

## Island (Fix It Button + Dictation Bar)

The "Fix It" button on the island has really bad UI, and the functionality is really bad. It doesn't actually work properly. Like, it shows up after each time — it stops the island from going away after you've dictated. It's just really bad.

Same thing with the entire form button as well. It's just not great placement.

I feel like the island needs to be improved. The dictation island as a whole — its behaviour, its buttons, its placement, the way it appears and disappears — it all needs another pass.
