In plain terms

This page is a map of every document in the Mumble project. If you're new and want to understand the project, start with README.html (the operating manual). If you're looking for something specific, use this index. Documents are grouped by where they live and what they're for, with a one-line summary and a freshness indicator so you know what's current and what's historical.
