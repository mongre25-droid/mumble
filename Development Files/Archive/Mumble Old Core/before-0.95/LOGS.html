2Milestone chronology

In plain terms

Mumble has lived through three big chapters. First the "classic era," where a plain little app grew into a polished, premium product. Then the "Big Shift," where the app stopped asking you to choose a mode and started figuring it out for you. Then the "v1 reorg," a spring-cleaning that moved everything into a tidy new home.

1
The classic era — v2.x → v3.17, through 2026-06

Mumble grew from a Tkinter app into a premium product: the black-and-gold liquid-glass window replaced Tkinter (v3.0.0); the unified History/Deck hub, Stats with real insights, the floating in-process island, the Reader (document-to-audio via OpenRouter TTS), instant web search, mouse-button bindings, personal vocabulary, and the multi-provider AI layer (Cerebras/OpenAI/Anthropic/OpenRouter/DeepSeek/Groq with a live model dropdown) all landed in this era. Local LLM (Ollama/LM Studio) support was added and then removed in v3.17.0 as unfit for non-technical users. The macOS and Linux ports were stood up as one-to-one replicas of the Windows brain.

2
The Big Shift — v0.9, 2026-06

A deliberate version reset and a philosophy change: you no longer pick modes — Mumble infers them. Dictate a list → bullets; a message → email; otherwise clean text. The one explicit mode is Prompt, a sticky toggle on the island's [ ✦ Prompt ] [ Deck ] companion bar. Reply and Convert became Deck actions rather than dictation modes; the old "hold Right-Shift and say a keyword" mechanism was retired. Cloud sync (Supabase) and opt-in cloud transcription were added. The two history actions were split — Ctrl+Alt+V = paste latest, Ctrl+Alt+H = open the Deck.

3
The v1 repository reorg — 2026-06-27

The accumulated workspace ("The Official Mumble") was audited file-by-file and reorganised into the clean Mumble v1 repository: runtime to Internal/ (with the ports under Internal/Ports/), the four core docs rebuilt, dev material curated into Development Files/Other/, and obsolete one-time artifacts left behind (see the migration audit). See §3.

2026-07-12 — Windows transcription latency optimisation

Reworked the production release-to-paste path after the real Windows log showed ordinary small.en calls around 1.5–2 seconds but rare decoder retries and overlapping stop-time work stretching individual chunks to 15 seconds, minutes, and queued lock timeouts.

  • ✓ decoder Ordinary faster-whisper calls now use one deterministic greedy pass (temperature=0, best_of=1) and skip timestamp-token decoding unless a word-aligned mode actually needs it.
  • ✓ streaming The live threshold moved from five to four seconds; event-driven polling replaced the 300 ms sleep; key release now harvests an in-flight same-session chunk once instead of discarding it, waiting three seconds, and decoding overlapping audio again.
  • ✓ concurrency Recording ids, claim checks and per-session idle events reject stale workers across stop, a newer recording, and sleep/resume. Failed chunks leave the seam untouched so the authoritative tail still covers them.
  • ✓ Windows CPU Automatic CTranslate2 sizing now uses a physical-core budget (8 on the Ryzen Z1 Extreme audit machine) instead of assigning 14 logical threads. Explicit cpu_threads still wins.
  • ✓ instant text Everyday Text defaults to deterministic local cleanup and paste without a network-polishing round trip. The new Settings switch can restore AI polishing; explicit Prompt and other AI modes are unchanged.
  • ✓ evidence Added release-to-visible-paste timing for stream drain, tail STT, shaping and Ctrl+V; removed unconditional per-dictation full garbage collection; expanded regression coverage for timestamp selection, stop/claim races, stale sessions and thread sizing. Focused verification: core regressions green, stream seam 16/16, performance 90/90.

2026-07-15 — Control retired; Mumble Search shipped in source

Windows + Linux experimental

Removed the autonomous Computer Control planner, executor, approval UI, wake service and UI-automation dependency. In its place, Mumble now provides an experimental local launcher for Windows and Linux. It discovers applications, files and folders from bounded local roots; ranks exact, prefix, token, acronym and subsequence matches; learns only explicit favourites and use recency; and offers open, reveal, copy-path and favourite actions. macOS deliberately has no Search loader or bridge because the platform already ships Spotlight and Finder.

The security boundary is intentionally narrow: queries are never evaluated as commands, result IDs are opaque, and actions are accepted only for entries in the current local index. The index is bounded, stored locally, refreshed in the background and exposes a low-ranked web-search fallback without sending the local index anywhere.

Reader gained in-document search with Ctrl/Cmd+F, bounded highlights and Enter/Shift+Enter navigation. Meetings gained cached library filtering plus transcript filtering and highlighting in the detail view. The canonical UI and Linux port carry both improvements.

Research and implementation boundary

  • Flow Launcher, Ueli and Microsoft PowerToys were reviewed as MIT-licensed references for provider-oriented discovery, keyboard-first interaction and explicit result actions.
  • No source, artwork, prompt text or bundled binary from those projects was copied. Mumble Search is an original standard-library implementation using Mumble's existing WebUI bridge.
  • The retired Control notices and dependencies were removed where no longer used; retained comtypes, pywin32 and sherpa-onnx notices cover other live Mumble runtime paths.

Verification

  • Authoritative offline suite: 65/65 scripts passed in 360.84 seconds with a 180-second per-script ceiling.
  • Focused checks: Search engine/UI/port tests, Reader and Meetings regressions, cloud sync, core regressions, WebUI API, Linux release-builder tests, Python compilation, fatal flake8, Bandit and JavaScript syntax all passed.
  • Live discovery probe: the Windows index discovered 177 installed applications and de-duplicated equivalent launcher entries by display name.
