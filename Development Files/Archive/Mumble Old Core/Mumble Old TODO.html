Summary

This document is the single authoritative master to-do list for the Mumble v1.0 release. It consolidates every actionable item from the comprehensive 2026-07-04 Release Audit — organised by category, annotated with priority, suggested fixes, and roadmap references (R1–R88). It also cross-references the 141 macOS and Linux audit issues that were fixed during this mission.

Three critical areas are blocking v1.0: (1) Infrastructure & Distribution — no CI/CD, no code signing, no automated builds; (2) Code Architecture — 5K-line monolithic controller, ~4,500 lines of duplicated port code; (3) Testing & Quality — three critical modules untested, no centralized test runner, no CI.

The roadmap in the audit condenses ~188 items into 88 prioritised items (R1–R88) plus 17 release-specific items (REL-1–REL-17). Each item below is tagged with its roadmap reference where applicable.
