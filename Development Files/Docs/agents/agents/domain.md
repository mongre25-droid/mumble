# Domain documentation

Mumble is a single-context project. Before substantive work, read `Development Files/Core/README.html`, then use the relevant authoritative Core record:

- `STATUS.html` for current priorities, known bugs, technical debt, and open work.
- `HANDBOOK.html` for architecture, testing, delivery, and operating procedures.
- `LOGS.html` for completed history.
- `MUMBLE_MASTER_SYSTEM_DOCUMENTATION.md` for the detailed system contract when the task materially changes it.

Do not create duplicate `CONTEXT.md` or `docs/adr/` records. The Core records are Mumble's established source of truth; use their terminology in issues, plans, tests, and implementation notes.
