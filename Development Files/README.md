# Mumble development files

This folder contains the material needed to understand, build, verify, and communicate about Mumble. The application itself remains under `../Internal/`.

| Area | Purpose |
| --- | --- |
| `Core/` | The four current project records: README, STATUS, HANDBOOK, and LOGS. |
| `Docs/` | Development guidance and project documentation. |
| `GitHub/` | All maintained repository-support files: issue forms, labels, helper scripts, agent guidance, and the development ignore rules. |
| `Marketing/` | The current product website and campaign material. |
| `Research/` | Source-backed investigations and working research. |
| `Tooling/` | Build, packaging, verification, and synchronization helpers. |
| `Legal/` | Development-facing legal material and the maintained license record. |
| `_assets/` | Shared styling for the HTML development records. |

Start with `Core/README.html`, then check `Core/STATUS.html` before making a change. Use `Core/HANDBOOK.html` for procedures and `Core/LOGS.html` for completed history.

The root `AGENTS.md`, `.gitignore`, and `LICENSE` remain only because GitHub, Git, and development tools require those conventional root locations. Their maintained project copies live in `GitHub/` and `Legal/`; do not create additional copies elsewhere.
