# Mumble project guidance

The maintained project instructions are in [`Development Files/GitHub/AGENTS.md`](Development%20Files/GitHub/AGENTS.md). Read that file before substantive work, then read [`Development Files/Core/README.html`](Development%20Files/Core/README.html).

This small root file exists because agent tools discover `AGENTS.md` from the repository root. The full instructions and development records live under `Development Files/`.

## Agent skills

### Issue tracker

Substantial work, specifications, and decisions are tracked in this repository's GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

The five Matt Pocock workflow roles use the repository's matching GitHub labels. See `docs/agents/triage-labels.md`.

### Domain docs

Mumble uses one project context and its four established Core records rather than a duplicate context or ADR tree. See `docs/agents/domain.md`.
