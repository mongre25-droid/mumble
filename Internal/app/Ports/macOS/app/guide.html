▮▮▮ Mumble

Speak. It types.

Private voice-to-text for your Mac.

First: grant two permissions

macOS will ask the first time — or turn them on in System Settings ▸ Privacy & Security:

  • Microphone — so Mumble can hear you.
  • Accessibility — so the global hotkey works and Mumble can paste for you.

If the hotkey ever does nothing, it's almost always the Accessibility permission — add Mumble (or your Terminal/Python) under Accessibility and try again.

How to use it

  1. Click into any text field (an email, a chat, a doc — anywhere).
  2. Press Control + Option + M.
  3. Speak naturally.
  4. Press Control + Option + M again — your words appear.

A small island appears near the bottom of the current screen while it listens and works, glowing in the colour of the mode it's writing. Re-paste your last result anywhere with Control + Option + V.

Turn any text into a prompt — use the Deck: highlight some text and hit Convert on any Deck item to route it into another Smart Mode (email, prompt, reply). Mumble files the result under that mode. If it can’t paste (say, a read-only page), the result is kept on your clipboard and the island shows ⌃ ⌥ V to remind you to paste it yourself.

Smart Modes — one Prompt toggle, everything else in the Deck

Ordinary dictation always produces clean text. Turn Prompt on from the island when you want a rough idea shaped into an AI prompt. Use the Deck for Email, Reply, Foreign, lists and other transformations so the source and action are always deliberate. Spoken mode names are ordinary words.

Pro Mode & privacy

Local transcription keeps audio on your Mac. Optional Cloud transcription sends each audio clip to the selected provider. Pro Mode sends transcript text to the selected AI provider for shaping. The Home privacy badge shows which transcription mode is active.

  • Turn Pro Mode off (menu ▸ Pro Mode) to keep everything on your Mac — it uses an instant built-in builder instead.
  • You can add your own DeepSeek key (menu ▸ Pro Mode ▸ Set your DeepSeek key) — optional.
  • If the key is ever unavailable, Mumble automatically falls back so it keeps working, and the island shows a small ring when it's running offline.

Memory & context: Mumble does not record or remember your conversations. The only context it uses is in Reply mode — the message you copied.

Sharing Mumble

Send a friend the MacMumble.zip file. They unzip it, run Install Mumble.command, approve the Microphone + Accessibility permissions, and it lives in their menu bar. (Mac users get the Mac zip; Windows users get the Windows zip — they're separate.)
