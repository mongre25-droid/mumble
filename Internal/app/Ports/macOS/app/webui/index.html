Listening & transcriptionYour microphone, engine, language, and processing quality

Microphone

Input device

By default transcription runs entirely on-device with faster-whisper — your audio never leaves the machine. (An optional Cloud mode under Transcription can send audio to a hosted service for extra speed.)

Transcription

Transcription engine
Local transcription runs entirely on your device. Your audio never leaves this machine — it works offline, it's private by default, and nothing is ever uploaded. Recommended for most users.
Cloud transcription uploads each audio clip to a low-latency hosted Whisper service — faster on older hardware, but your audio is sent to the provider you choose. Turn this on only if you're comfortable with that privacy trade-off. If a request fails, Mumble silently falls back to local. Network required.

Model & language

Mumble runs faster-whisper speech models on your device. Bigger models are more accurate but need more RAM and CPU time. If a model fails to load, Mumble falls back to a safe default so transcription remains available.

Languages

Turn off “English only” if you dictate in other languages. The exact model remains available under Advanced.

Advanced — pick the exact model
Accuracy model

Higher accuracy tiers increase local hardware strain and extend transcription processing time.

Language

Bigger models are more accurate but slower to load and run. Everything runs locally on your CPU (or GPU if available). Languages other than English need a multilingual model — the “English only” models ignore the language setting.

⚠ Maximum Accuracy uses a large model (≈1.5 GB+) and is much slower. Not recommended unless you have a high-end CPU.

Connect your AI provider
Your AI provider cleans up transcripts and powers Smart Modes. Only text is sent — your audio stays local. Cerebras is free and fast.
AI provider
  1. Click the button above to open your provider's API keys page
  2. Sign in (Google works on Cerebras)
  3. Go to API Keys and create one named “Mumble”
  4. Copy the key (starts with csk- or sk-or-)
  5. Paste it below and hit Save & Test
  6. Done — AI polish is on

⚠ Without a valid API key, AI polish and every Smart Mode (Prompt, Email, Foreign, Convert) stay off. Mumble still transcribes locally, but you lose the cleanup and modes that make it shine. You can add a key any time in Settings → AI.
