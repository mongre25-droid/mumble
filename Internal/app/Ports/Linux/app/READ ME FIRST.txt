============================================================
  MUMBLE — local-first voice-to-text for Linux
  Talk, and it types in the app you are using.
============================================================

INSTALL

  Mumble's locked runtime dependencies require Python 3.12 or newer. The
  installer checks this before creating its virtual environment and prints a
  clear error if the distro's default Python is too old.

  1) Move the whole Linux Mumble folder somewhere permanent.
  2) Open a terminal in that folder and run:

       chmod +x install.sh
       ./install.sh

  The installer creates an isolated Python environment, installs the required
  GTK/audio packages, downloads the default speech model, adds Mumble to your
  application menu, and enables login autostart. Run it again to repair or
  update an existing installation.

HOW TO USE IT

  - Tap Ctrl + Super, speak, then tap Ctrl + Super again.
  - Ctrl + Alt + V pastes the latest transcript.
  - Ctrl + Alt + D opens History and the Deck.
  - Ctrl + Alt + S searches selected text, or starts voice search.
  - Choose Prompt, Email, or Reply from the island mode deck when needed.

LINUX NOTES

  Mumble keeps X11 and Wayland separate. On Wayland, global shortcuts use the
  desktop approval window only when the live xdg-desktop-portal
  GlobalShortcuts service is available. Approve each shortcut when GNOME or KDE
  asks. If that service cannot be proved, Mumble reports a degraded or unknown
  route and does not silently send shortcuts through XWayland.

  On X11, global hotkeys need permission to read input devices. If the app
  warns about permissions, run:

       sudo usermod -aG input "$USER"

  Then log out and back in. Wayland paste uses wl-clipboard plus wtype or the
  permission-dependent ydotool route; X11 uses xclip or xsel plus xdotool. When
  a compositor blocks insertion or drag, Mumble keeps the result saved and
  offers Copy, Open, or Show in folder instead of claiming success.
  On X11, indexed files and folders use a GTK-owned URI drag; whether the target
  accepts the drop still requires a real desktop check.

  Mumble Find asks GNOME LocalSearch/Tracker or KDE Baloo first. A plocate result
  is labelled degraded because its filename database can be stale. No desktop
  index means local Find reports unsupported; it does not crawl your home folder.

  Audio reports PipeWire, PulseAudio, permission denial, and no-device states
  separately. A temporarily missing saved microphone is used only as a one-run
  fallback and is not erased from Settings.

  Flatpak, Snap, compositor policy, and distribution package availability can
  limit these routes. Source checks are not proof of real GNOME, KDE, X11,
  Wayland, microphone, tray, autostart, focus, clipboard, or drag behaviour.
  Login autostart is ready only after Mumble can validate its enabled XDG entry
  and installed launch route; otherwise Settings keeps the limitation visible.

PRIVACY

  Local transcription stays on this computer. Optional Cloud transcription and
  AI features send the disclosed audio or text only to the provider selected in
  Settings.

REMOVE

  Run ./uninstall.sh (or choose “Uninstall Mumble” from the application menu),
  then delete the Mumble folder. User data is kept by default. To remove it too:

       ./uninstall.sh --purge-data
