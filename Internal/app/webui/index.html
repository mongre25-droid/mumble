Clean, plain text. Just talk — Mumble cleans up your speech and automatically shapes it into clean, punctuated text. Prompt is the one thing you switch on yourself (on the floating island, or right here) when you want a polished AI prompt. Convert now lives in the Deck.

Local language & accuracyMumble chooses sensible defaults automatically Advanced

Mumble runs faster-whisper speech models on your device and selects a suitable model automatically. If a model fails to load, Mumble falls back to a safe default so transcription always works. GPU acceleration (CUDA) is used automatically when available; otherwise everything runs efficiently on CPU.

Languages

Mumble picks the right on-device speech model for this device and language — you don’t need to choose one. Turn off “English only” if you dictate in other languages.

Advanced — pick the exact model
Accuracy model

Higher accuracy tiers increase local hardware strain and extend transcription processing time.

Language

Bigger models are more accurate but slower to load and run. Everything runs locally on your CPU (or GPU if available). Languages other than English need a multilingual model — the “English only” models ignore the language setting.

⚠ Maximum Accuracy uses a large model (≈1.5 GB+) and is much slower. Not recommended unless you have a high-end CPU.

Connect your AI provider
Your AI provider cleans up transcripts and powers Smart Modes. Only text is sent — your audio stays local. Cerebras is the recommended low-latency option and currently offers a rate-limited free tier.
AI provider
  1. Click the button above to open your provider's API keys page
  2. Sign in (Google works on Cerebras)
  3. Go to API Keys and create one named “Mumble”
  4. Copy the key (starts with csk- or sk-or-)
  5. Paste it below and hit Save & Test
  6. Done — AI polish is on

Without a valid API key, cloud polish and cloud-powered modes are unavailable. Mumble still transcribes locally and preserves its deterministic on-device formatting. You can add a key any time in Settings → AI.
